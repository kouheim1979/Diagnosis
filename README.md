# MediScope（メディスコープ）

心理テスト、性格診断、発達特性やメンタルヘルスのセルフチェックに関する信頼できるリンクを分類・検索する静的サイトです。

- `index.html`: MediScope トップページ。ADHD/ASD・ストレス・サイコパシー傾向・ビッグファイブ・16タイプ等。**DISCは掲載していません**。
- `business/index.html`: WorkStyle Lab（仕事・チーム向け）。DISCの4つの行動傾向を参考に作成したオリジナル16問チェック。公式DiSC製品や認定検査ではありません。

第三者の心理テストを無断複製せず、提供元サイトへのリンクとして案内します。医療上の診断・採用評価には使用しないでください。

## GitHub Pages

Pages を `main` ブランチの `/ (root)` から配信すると、トップは `/Diagnosis/`、独立した仕事向けページは `/Diagnosis/business/` で開けます。

旧 Chroma Sort の HTML ファイルは削除して、新サイトのファイルに置き換えています。
