# MediScope / メディスコープ

オリジナルの心理・性格セルフチェックを提供する静的Webサイト。

## 構成
- index.html — 全テストの検索・カテゴリ・回答画面
- app.js — 独自作成の設問、回答・集計処理
- .nojekyll — GitHub Pages用

## 現在のチェック
1. 注意・段取りの困りごと（ADHDを考えるきっかけ）
2. 対人・感覚の特徴（ASDを考えるきっかけ）
3. こころの負担
4. 対人・共感・衝動性（サイコパシーという話題を考えるきっかけ）
5. 感覚・刺激への敏感さ（HSPなど）
6. ビッグファイブ風5特性（独自15問）
7. 16通りの対話スタイル（独自12問）

いずれも独自制作・**非標準化・未検証**です。外部サイトの質問票のコピーはしていません。診断名、精神疾患の確率、発達障害の有無、重症度を判定するものではありません。入力した回答は端末内で集計するだけで保存・送信されません。
